# Changelog

## 1.2.0 — 27 October 2026

Supplementary Note S2, section S2.7, now reports the uncertainty and robustness analyses added to manuscript v0.24, with Tables S4–S7 and CSV copies under `methods/`:

- organisation-cluster bootstrap intervals alongside the engineer-cluster interval, with and without the largest organisation (Table S4);
- strength- and deflection-governed means in the 46 shared templates at each group's own and at common template weights (Table S5);
- the deflection-governed share by band with template weights held fixed (Table S6);
- the full specification grid for the strength-governed, deflection-governed, headline and bearing-inclusive sets (Table S7).

The aggregation-sensitivity definitions are stated in full, including the four materials used for equal material weighting. The rows without the largest organisation omit engineer and group counts, in line with the data owner's description of that account. No per-template result is released.

The PDF build script now sets column widths for each table and reads the version from the Markdown source. It also renders superscripts that the Arial font lacks, which fixes the exponent in S2.8. S1 is unchanged.
